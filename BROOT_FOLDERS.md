# Сворачивание папок Broot

Обычный запуск: `broot .`.

Ползунок справа от дерева скрыт. Колесо мыши и перемещение по дереву работают как прежде.

События тачпада обрабатываются пачками без ожидания следующего события. Одинаковые накопившиеся шаги выполняются одним перемещением; смена направления, клики и клавиши сохраняют порядок. Прокрутка останавливается у края списка и не переходит циклически на другой конец. Наблюдение за файлами сохраняется во время прокрутки и использует наблюдение за папками вместо отдельной подписки на каждый файл. Обёртка передаёт ввод без блокировки чтения вывода.

Git-статусы видны и при открытии общей папки вне Git. Каждый показанный файл относится к своему ближайшему репозиторию, включая вложенные репозитории, submodule и worktree с `.git`-файлом. `M` — modified, `U` — untracked, `A` — добавлен в индекс, `S` — staged. Свёрнутая папка репозитория показывает приоритетный статус изменений внутри; ignored-файлы сами по себе не помечают чистый репозиторий. Статусы обновляются вместе с деревом, принудительно — F5.

- Папки при запуске свёрнуты: синий **▸** рядом с именем.
- Клик по **▸** раскрывает папку на месте; **▾** сворачивает её.
- Клик по имени только выделяет строку; Enter и двойной клик по имени сохраняют обычный переход внутрь.
- Состояние раскрытых веток сохраняется при автообновлении и F5 в текущем запуске.
- Поиск заглядывает внутрь свёрнутых папок и временно показывает найденные пути. При выходе из поиска возвращается исходное дерево.
- Синие кружочки выбора, ⌘C для путей и Esc для снятия выбора продолжают работать отдельно от треугольников.

Установлена отдельная локальная сборка **Broot 1.61.0**:
`~/.local/opt/broot-folders/1.61.0/bin/broot`.
Её выбирает существующая обёртка `~/.config/broot/file-import.py`.
Официальный Homebrew-бинарник не заменён.

Временно вернуть обычное дерево: `BROOT_CLICK_FOLDERS=0 broot .`.

После обновления Homebrew проверенная приватная сборка остаётся выбранной. Официальный бинарник доступен через `BROOT_OFFICIAL=1 broot`. Перенос патча на новую базу выполняется явно с тестами.

Исходники текущей сборки: `.build/broot-folders-src`.
Изменения: `broot-folders.patch`, `broot-no-scrollbar.patch`, `broot-nested-git.patch`, `broot-scroll.patch`, `broot-untracked-u.patch`, `broot-input-events.rs`.
Повторная сборка и проверки: `zsh build-broot-folders.zsh`.
Установка: `python3 install-broot-folders.py`.
Патч локальный; в исходный проект ничего не публиковалось.

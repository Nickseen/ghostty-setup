# Просмотр вложений по клику

Локальный клиент на базе Codex CLI 0.169.0:

- Клик по миниатюре над черновиком открывает исходную картинку крупно внутри панели Codex.
- Клик по `[Image #N]` в черновике открывает соответствующее вложение.
- Метки `[Image #N]` в отправленных сообщениях тоже открывают локальные картинки, пока их файлы существуют.
- Esc, Enter или q закрывают просмотр. Черновик и положение истории сохраняются.
- При изменении размера панели картинка вписывается заново с сохранением пропорций.

Требуется Fullscreen и `allow-passthrough all` в tmux; эти настройки уже включены.

Сборка: `zsh build-codex-image-preview.zsh`.
Установка проверенной сборки: `python3 install-codex-image-preview.py`.

Официальный Homebrew-пакет не меняется. Личный `~/.local/bin/codex` сохраняет
проверенную приватную сборку независимо от обновлений Homebrew. Официальная
версия доступна через `CODEX_OFFICIAL=1 codex`. Перенос патча на новую базу требует
пересборки и тестов; это не происходит автоматически.

Проверка: `ghostty-setup doctor`. Восстановление графики: `ghostty-setup repair`,
после чего переоткрой затронутый Codex через `codex resume ID`.

# Broot: быстрые действия

Запуск: `broot .` в папке проекта.
Возле глазика в нижней строке: `0:.файлы · ⌘C:пути · ⌘R:Finder`.

| Клавиша | Действие |
|---|---|
| 0 | Показать / скрыть файлы и папки с точкой (в режиме навигации) |
| Клик по ▸ / ▾ | Раскрыть / свернуть папку в дереве |
| ⌘ + клик | Добавить файл в выбор; повторный клик снимает выбор |
| ⌘C | Скопировать полные пути выбранных файлов, по одному на строку; без множественного выбора — путь текущего файла |
| ⌘R | Reveal in Finder: открыть Finder и выделить выбранный файл или папку |
| Esc | Снять множественное выделение; без него — обычное поведение Escape |
| F2 | Переименовать выбранный файл или папку |
| F3 | Создать файл в выбранной папке: имя в окне macOS → Создать |
| ⇧F3 | Создать папку, включая вложенные пути |
| F4 | Скопировать путь относительно корня Git-проекта; вне Git — относительно открытой папки |
| F6 | Открыть Git diff выбранного файла |
| ⌃P | Открыть выбранный файл в отдельном окне просмотра |
| F8 | Отменить последнее удаление через Broot в этом проекте |
| ⌘⌫ | Переместить выбранный файл или вложенную папку в Корзину |
| Пробел / ⌃O | Код и текст → подсвеченный исходник в Quick Look; PDF, картинки и документы → обычный Quick Look |
| Esc в окне Quick Look | Закрыть просмотр и вернуться к Broot |
| ⌘V / перенос из Finder | Скопировать файлы в выбранную папку |
| ⌃C | Выйти из Broot |
| F1 / ? | Полная справка Broot |

Если F-клавиши регулируют яркость или звук, удерживай **Fn**.

Выбранные через ⌘ + клик файлы отмечены яркими синими кружками в дереве. Дополнительная панель выбора не открывается.

Git-метки и автообновление включаются при каждом обычном запуске `broot`.
Скрытые и игнорируемые файлы показываются по умолчанию, включая `.git`, `.gitignore` и `.env`.
Вставленные существующие абсолютные пути файлов тоже копируются в выбранную папку. Импорт не зависит от содержимого файлового буфера Finder; обычный текст по-прежнему вставляется в строку ввода. Ошибка импорта не превращает путь в поисковый запрос.
Папка выделена — действия выполняются в ней. Файл выделен — создание и вставка идут в его папку.

Иконки используют отдельный шрифт **Broot Icons Visual Studio Code**.
Основной шрифт Ghostty не меняется.

История удаления сохраняется между запусками в `~/.local/state/broot/trash-history/`.
F8 восстанавливает удаления через Broot, пока файл остаётся в Корзине. Уже существующий файл не заменяется.
Вне Git история привязана к открытой корневой папке дерева.

Дополнительные команды: `:nf имя.txt`, `:nd папка`, `:rp` (путь), `:diff`, `:undo`, `:gs` (только Git-изменения), `:watch` (переключить автообновление).
`:reveal` выполняет то же действие, что ⌘R. Сочетание активно, когда Ghostty на переднем плане и выбрана панель Broot.
